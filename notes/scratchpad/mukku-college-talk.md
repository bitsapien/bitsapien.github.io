Objective: To encourage undergrads to contribute to open source projects.


Summary: Contributing to open source software is the one of the most optimised ways to grow in the software industry for 2 main reasons:
1. Nothing teaches you the art of coding as contributing to open source projetcs. You write better code when you read good code.
2. Your code will be reviewed for free, and help you to improve your programming skills.
3. You contribute to the community that will help you nurture your entire coareer.
4. You make amazing contacts and network, so you don't have to "interview" anymore.
