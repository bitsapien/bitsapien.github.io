Shortcuts:

* File editing : SPC .
* Edit config: SPC f p 
* Split pane : SPC w v 
* Paste using p 

* Projects:
    * Add a project - SPC p p
    * Find a file in project - SPC SPC
    * Recent files - SPC f r
    * Neotree - SPC o p
        * create file - c (end with / for a directory)
    * List workspace buffers : SPC ,
        * List all buffers - SPC <
    * Search - SPC s p
    * Invalidate cache - SPC p I 
* Text
    * Jump to a string : g s SPC and type 
    * Learn AVY 😬
    * Multiline edit - Meta D 
    * Comment/uncomment - M-;
* Other:
    * To cancel type C-g\
    * Doom refresh everytime you make a config change 
    * Use `bin/doom upgrade` to update Doom
    * Do a doom update/upgrade regularly - probably set a cron ?
    * How to paste in the buffer below?
        * Ctrl -Y 
* Magit:
    * Pull and rebase - F u 
    * x - resetting 
* Emacs
    * Create new entry same level - C Enter
    * Promote/demote M + arrow keys
* Org
    * New heading: M Enter
    * Promote/demote: M left/right arrow key
    * http://doc.norang.ca/org-mode.html
