---
title: "Testing Frontend Apps, the Testing Library Way"
date: 2021-10-13T09:16:08+05:30
draft: true
---

* Create a project
* Dont write a test on every new component you create
* Write tests only when a new feature or a feature update comes in.
* Do not mock application level configs (eg: routes), instead import them in your tests.
* Try not using typescript in your tests, it is really not necessary
