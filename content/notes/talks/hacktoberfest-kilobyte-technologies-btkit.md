1. *Learn to write better/maintainable code*
_Nothing teaches you the art of coding as contributing to open source projetcs. You write better code when you read good code. Your code will be reviewed for free, and help you to improve your programming skills._

2. *Feel good* - You contribute to the community that will help you nurture your entire career.

3. *Become famous* - You make amazing contacts and network, so you don't have to "interview" anymore.




*How do I start?*

* Look up the issues list.
  * beginner or first contributor
* Try getting help to navigate the codebase.
* Open a PR, tag it as WIP, invite reviews.
* Don't spam, it hurts the communiuty and wastes precious time. Respect their time.
